# Site da barbearia Sandro Barber

Este repositório guarda **apenas o site** (arquivos estáticos: HTML, CSS, JavaScript e
imagens). Ele existe para publicar o site pelo GitHub Pages.

- O site mostra serviços, preços, horários, produtos e o agendamento (que abre o WhatsApp
  da barbearia com a mensagem pronta).
- Atendimento: todos os dias, das 9h às 17h, de meia em meia hora, sem horário ao meio-dia.
- O aplicativo do dono e os dados de clientes **não ficam aqui** — eles vivem em um
  repositório privado.

Publicado automaticamente pelo GitHub Pages a partir da branch `main`.
